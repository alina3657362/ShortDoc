# ShortDoc API

ShortDoc API — сервис для работы с PDF-документами.

Сервис умеет:
- регистрировать и авторизовывать пользователей;
- извлекать текст из PDF без авторизации;
- создавать сокращённую версию PDF без авторизации;
- сохранять документы и их суммаризации в историю авторизованного пользователя;
- возвращать историю документов пользователя;
- возвращать сохранённую суммаризацию конкретного документа;
- удалять сохранённые документы.

## Текущая логика

Сервис работает в двух режимах.

### Без авторизации

Пользователь может загрузить PDF и сразу получить результат:

- текст документа;
- сокращённую версию документа.

В этом режиме документ не сохраняется в историю.

### С авторизацией

Пользователь может загрузить PDF в историю. Сервер сразу:

1. извлекает текст из PDF;
2. отправляет текст в LLM;
3. получает сокращённую версию;
4. сохраняет документ;
5. сохраняет готовую суммаризацию;
6. возвращает результат.



## Авторизация

Метод логина возвращает `access_token`.

Для авторизованных методов нужно передавать заголовок:

```http
Authorization: Bearer <access_token>
```

# Методы API

## Auth

### `POST /api/v1/auth/register`

Регистрирует нового пользователя.

Авторизация не требуется.

Поля запроса:
- `email` — почта пользователя;
- `nickname` — ник пользователя;
- `password` — пароль.

### `POST /api/v1/auth/login`

Авторизует пользователя по email и паролю.

Авторизация не требуется.

Поля запроса:
- `email` — почта пользователя;
- `password` — пароль.

Возвращает:
- `access_token`;
- `token_type`;
- данные пользователя.

## Documents

### `POST /api/v1/documents/extract-text`

Извлекает текст из PDF-файла.

Авторизация не требуется.

Используется, когда нужно просто получить текст из документа без сохранения в историю.

Принимает:
- `file` — PDF-файл.

Возвращает:
- `filename`;
- `text`.

### `POST /api/v1/documents/summarize`

Создаёт сокращённую версию PDF-документа.

Авторизация не требуется.

Используется, когда пользователь хочет получить summary без сохранения документа в историю.

Внутри метода:
1. проверяется файл;
2. из PDF извлекается текст;
3. текст отправляется в LLM;
4. результат возвращается пользователю.

Принимает:
- `file` — PDF-файл.

Возвращает:
- `filename`;
- `summary`.

### `POST /api/v1/documents`

Загружает PDF-документ в историю авторизованного пользователя.

Авторизация требуется.

Внутри метода:
1. проверяется access token;
2. определяется текущий пользователь;
3. проверяется файл;
4. из PDF извлекается текст;
5. текст отправляется в LLM;
6. создаётся сокращённая версия;
7. документ сохраняется в историю пользователя;
8. суммаризация сохраняется для этого документа.

Принимает:
- `file` — PDF-файл.

Возвращает сохранённую суммаризацию документа.

### `GET /api/v1/documents`

Возвращает историю документов авторизованного пользователя.

Авторизация требуется.

Метод возвращает только документы текущего пользователя.

Возвращает:
- список документов пользователя.

### `GET /api/v1/documents/{document_id}/summary`

Возвращает сохранённую суммаризацию конкретного документа.

Авторизация требуется.

Метод проверяет, что документ принадлежит текущему пользователю. Если документ не найден или принадлежит другому пользователю, возвращается ошибка `404`.

Возвращает:
- id суммаризации;
- id документа;
- текст суммаризации;
- дату создания.

### `DELETE /api/v1/documents/{document_id}`

Удаляет сохранённый документ авторизованного пользователя.

Авторизация требуется.

Метод удаляет:
- документ;
- связанную с ним суммаризацию.

Если документ не найден или принадлежит другому пользователю, возвращается ошибка `404`.

# Итоговая таблица методов

| Метод | Авторизация | Что делает |
|---|---:|---|
| `POST /api/v1/auth/register` | Нет | Регистрирует пользователя |
| `POST /api/v1/auth/login` | Нет | Авторизует пользователя и возвращает токен |
| `POST /api/v1/documents/extract-text` | Нет | Извлекает текст из PDF |
| `POST /api/v1/documents/summarize` | Нет | Возвращает summary PDF без сохранения |
| `POST /api/v1/documents` | Да | Создаёт summary и сохраняет документ в историю |
| `GET /api/v1/documents` | Да | Возвращает историю документов пользователя |
| `GET /api/v1/documents/{document_id}/summary` | Да | Возвращает сохранённую summary документа |
| `DELETE /api/v1/documents/{document_id}` | Да | Удаляет документ пользователя |
